# Webfonts

本目錄中的 WOFF2 字體僅保留 `党項語藏文轉寫方案.html` 實際使用的字形，並保留藏文等文字所需的 OpenType 排版功能。

| 字體 | 用途 | 來源與授權 |
|---|---|---|
| Noto Serif Tangut | 西夏文 | [notofonts/tangut](https://github.com/notofonts/tangut)，SIL OFL 1.1 |
| Noto Serif Tibetan | 藏文 | [notofonts/tibetan](https://github.com/notofonts/tibetan)，SIL OFL 1.1 |
| Noto Serif TC / SC fallback | 繁體中文及異體字 `爲` | [notofonts/noto-cjk](https://github.com/notofonts/noto-cjk)，SIL OFL 1.1 |
| Libertinus Serif | 拉丁字母與音標 | [alerque/libertinus](https://github.com/alerque/libertinus)，SIL OFL 1.1 |

各字體的完整授權文字位於同目錄的 `OFL-*.txt`。若 HTML 新增字符，必須重新生成相應子集。
